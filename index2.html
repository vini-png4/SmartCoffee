Comandos Git

Git Init


        git init - Inicializa repositório e mantem um histórico

Git Status


        git status - Podemos visualizar o funcionamento correto do repositório

Git Add


        git add - Para preparar os arquivos da pasta
        git add - nome_pasta ou arquivo
        git add .

Git Commit


        git commit - Irá enviar uma mensagem de confirmação para o Github
        git commit - m "Mensagem que desejo"

Git Log


        git log - Irá exibir o histório de commits
        git log --oneline - Irá exibir o histório de commits resumido

Git Branch


        git branch - Irá exibir as branches existentes
        git branch nome_da_branch - Irá criar uma nova branch
        git checkout nome_da_branch - Irá alterar para o branch especificada
        git branch -M main - Irá renomear a branch atual para main

Git Remote


        git remote - Irá exibit os remotos configurado
        git remote add origin url - Irá adicionar um novo remote
        git push origin main - Irá enviar alterações para o remote
        git remote add origin link_repositorio
        git remote -v - Irá mostrar a URL configurada do origin

Git Push


        git push - Irá enviar alterações para o remote
        git push origin main - Irá enviar alterações para o remote
        git push -u origin main - Irá enviar alterações para o remote e definir a branch atual como upstream
        git push - Enviar atualizações para o remote
